# javascript-racingcar-precourse

우아한 테크코스 2주차 과제 : 자동자 경주 게임(Racing Car Game)

## ✨ 기능 목록 (Feature List)

### 입력 기능

- 경주할 자동차 이름을 입력받는다.
  - "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 문자열을 출력한다.
  - Console.readLineAsync()를 사용하여 사용자로부터 입력을 받는다.
  - 이름은 쉼표(`,`)로 구분한다.
  - 각 자동차 이름은 5자 이하로 제한한다.
- 시도할 횟수를 입력받는다.

### 게임 진행 기능

- 입력받은 횟수만큼 자동차 경주를 진행한다.
- 매 시도마다 각 자동차는 무작위 값에 따라 전진 여부가 결정된다.
  - 전진 조건은 `@woowacourse/mission-utils`의 `Random.pickNumberInRange()`를 사용하여 판단한다.
  - 0~9까지 랜덤값을 받고, 4 이상일때만 전진하도록 한다
- 매 시도 후 각 자동차의 전진 상태를 출력한다.

### 우승자 판별 및 출력 기능

- 모든 시도가 끝난 후, 가장 많이 전진한 자동차를 우승자로 선정하여 출력한다.
- 우승자는 한 명 또는 여러 명이다.
- 공동 우승자일 경우 쉼표(`,`)로 구분하여 함께 출력한다.

### 예외 처리 기능

- 입력 기능
  - 잘못된 타입으로 입력받을 경우(숫자값, 불린값 등)
  - 입력한 자동차의 개수가 1개일 경우
  - 입력한 자동차의 이름이 5자가 초과되었을 경우
  - 자동차 이름이 중복될 경우
  - 입력받은 시도 횟수가 숫자값이 아닐 경우

### 테스트 기능

- 각 기능별 유효성 검증을 위한 테스트 코드를 작성한다.
- `Jest`를 사용하여 기능들이 정상적으로 동작하는지 확인한다.

---

### 프로그래밍 요구사항

- Node.js 22.19.0 버전에서 실행 가능해야 한다
- 외부 라이브러리 사용 금지
- 프로그램 종료 시 `process.exit()`를 호출하지 않는다
- Javascript Style Guide를 따른다
  - 영문 이외의 언어 사용 금지
  - 클래스 메서드 등의 이름에는 특수문자 사용 금지(예시: 함수이름 $handle)
  - 상수명은 SNAKE_CASE로 작성 (예시: const FIREFOX)
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용
- 3항 연산자를 쓰지 않는다
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들기
- Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인
- `@woowacourse/mission-utils`에서 제공하는 `Random` 및 `Console` API를 사용하여 구현해야 한다.
  - Random 값 추출은 `Random.pickNumberInRange()`를 활용한다.
  - 사용자의 값을 입력 및 출력하려면 `Console.readLineAsync()`와 `Console.print()`를 활용한다.
